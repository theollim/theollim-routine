더올림수학 학생 루틴 앱 — 세련된 디자인 수정본

구성
- index.html: 학생용 화면 전체
- api/links.js: Tally 링크 자동 연결
- api/checkin-status.js: 등원 전 체크인 제출일 확인
- study-log.js: 학습 완료 기록 전송

배포
1. 이 폴더 전체를 ZIP으로 압축합니다.
2. https://vercel.com/drop 에 ZIP 파일을 올립니다.
3. Vercel 프로젝트의 환경 변수에 필요한 값을 등록합니다.

필수 환경 변수
- TALLY_API_KEY
- NOTION_KEY

선택 환경 변수
- STUDY_DB_ID: 기본 학습 기록 DB가 아닌 다른 DB를 사용할 때만 등록합니다.

등원 전 체크인 확인
- 학생이 등원 버튼을 누르면 이름으로 최근 체크인과 등원 기록을 확인합니다.
- 한국시간 날짜 기준으로 전날까지 제출은 정상 처리, 당일 제출은 주황색,
  미제출은 빨간색 안내를 표시합니다.
- 정상 체크인은 짧게 확인한 뒤 등원 화면으로 자동 이동합니다.
- 이미 오늘 등원한 경우 중복 등원 안내를 표시합니다.
- Tally API를 확인할 수 없는 일시적 장애 때는 등원을 계속할 수 있습니다.
